Next.js frontend (MVP)

This folder contains a minimal Next.js app (JS) to replace the legacy templates/ui.html.

To run:
1. cd web
2. npm install
3. npm run dev

The app will run on http://localhost:3000 and talk to the backend at NEXT_PUBLIC_API_BASE (defaults to http://127.0.0.1:8000).

Progress: MVP pages implemented: / (members list) and /join?token=...
